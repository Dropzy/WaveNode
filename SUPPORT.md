# Support

Use GitHub Discussions or an issue for installation questions, reproducible bugs, and feature requests.

Before requesting help:

1. Read `README.md`, `DEPLOYMENT.md`, and `SECURITY.md`.
2. Check existing issues.
3. Include the WaveNode version, operating system, deployment method, and relevant sanitized logs.

Never attach music files, passwords, JWT secrets, database dumps, access tokens, or private filesystem paths.

Security vulnerabilities must follow `SECURITY.md` instead of a public support thread.
