# Code of Conduct

WaveNode contributors must keep project spaces respectful, constructive, and focused on the work.

## Expected Behavior

- Discuss ideas and code without personal attacks.
- Welcome contributors regardless of experience or background.
- Give actionable technical feedback and accept corrections professionally.
- Respect privacy, especially around personal music libraries, server paths, and account data.

## Unacceptable Behavior

- Harassment, discrimination, threats, or sustained disruption.
- Publishing another person's private information.
- Sharing credentials, tokens, private library data, or copyrighted music files.
- Using project spaces for spam or unrelated promotion.

Maintainers may edit or remove content and temporarily or permanently restrict participation when necessary to protect the community. Report conduct concerns privately through the repository's security or maintainer contact channel.
